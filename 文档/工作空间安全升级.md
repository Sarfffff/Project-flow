# 工作空间安全升级

本文保留前一版的测试记录；当前入口和数据库位置配置以同目录《设置与入口升级》为准。

## 本轮范围

实现恢复关联修复、备份保护、连接状态面板、设置页精简。保留上一版并行读取和 30 秒缓存机制，本轮没有重新改写 GitHub 全局渲染或缓存失效策略。

## 启用

1. 在原服务终端按 Ctrl+C 停止服务。
2. 使用原有数据库位置启动。默认数据库可双击项目根目录的“打开Flow.cmd”。如果此前使用 `--db` 自定义数据库，重启时必须继续传入同一个路径。
3. 私有仓库令牌在工作空间设置的密码框输入，不发到聊天、不写入源码或备份。
4. 刷新页面，进入“工作空间设置”。检查真实数据库位置及项目任务数量。

本次代码更新未停止原服务，未修改真实数据库，也未推送 GitHub。运行中的旧 Python 进程不支持新接口，因此未重启前新设置组件可能加载失败；重启并刷新后生效。启动时只新增备份元数据表，不覆盖现有项目、任务或 GitHub 关联。

## 备份范围

| 类型 | 格式 | 导出内容 | 恢复行为 |
| --- | --- | --- | --- |
| 项目与任务 | flow-backup-v1 | 项目、任务 | 覆盖项目任务、重置活动；保留现有 GitHub 配置和提交快照，按项目 ID 恢复有效关联 |
| 完整工作空间 | flow-workspace-v2 | 项目、任务、账号名称、仓库分支关联、最近 100 条/分支的提交摘要、最多 500 条活动 | 覆盖以上内容，并追加本次恢复活动 |

完整工作空间不是电脑或仓库镜像，不包括令牌、环境变量、源码文件、完整提交 diff、浏览器主题和备份历史。服务器内存中的令牌不会因恢复改变；若完整备份中的账号名称与令牌不匹配，请在工作空间设置重新连接正确账号。

备份最大 64 MB。项目最多 1000 个，任务最多 20000 个，完整备份最多 1000 条仓库分支关联。超限明确拒绝，不静默截断。

## 恢复保护

- 前端上传后，后端在内存数据库校验全部项目、任务、日期、关联、快照和活动结构。
- 预览显示当前与导入数量、恢复范围，以及旧关联中找不到的项目。
- 确认时携带预览的数据版本；其他页面更新项目任务后，本次恢复被拒绝，需重新预览。
- 数据删除前，写入 `<数据库所在目录>/<数据库文件主名>.backups/before-restore-<UTC时间>-<随机后缀>.json`。
- 安全备份使用完整工作空间格式，文件独占创建，写入并刷盘后原子改名。文件写入失败取消恢复；随后 SQL 出错会整体回滚。若 SQL 出错，已经生成的安全副本保留。
- 旧项目备份恢复后，相同项目 ID 的 GitHub 关联恢复；缺失项目的关联保留仓库和快照，只清空项目绑定。
- 恢复成功后清空后端读取缓存，并重置当前页面的 GitHub 关联状态。

安全备份在本地保留，不自动删除，不作为静态资源暴露。它可能包含私有仓库名称和提交消息，不是加密文件。请保护所在目录，定期另存到其他磁盘；同磁盘副本不能防止磁盘损坏。

“最近生成”是后端生成导出文件的时间，不代表浏览器已经完成保存。通过旧兼容接口 `/api/export` 导出不更新该时间；新设置页两种导出均记录时间。

## 设置页

- 顶栏明确写“本地服务已连接”，不再暗示 GitHub 联网成功。
- 状态卡展示 GitHub 配置、最近提交同步时间和 30 秒读取缓存说明。
- 点击“验证 GitHub 连接”才访问 GitHub，分别检查令牌账号或公开个人账号；账号验证不等于所有私有仓库均有权限。
- 数据库路径从后端实际配置读取，支持复制；最近安全备份也可复制位置。
- 设置刷新仅更新状态与备份提示区域，不主动发 GitHub 网络请求。
- 连接、备份置于上方；主题有文字选中标记与 aria-pressed；“关于与快捷键”默认折叠。
- 宽屏双列，中小屏单列；提高设置页说明文字对比度，不改变其他页面配色。

```powershell
node tests/test_frontend.cjs

```

当前通过 59 项后端测试、20 项通用前端检查、15 项 GitHub 展示检查、12 项 GitHub 异步检查、13 项设置交互检查，共 119 项。

后端直接执行真实 Handler 路由和 SQLite 逻辑，不占用应用端口；数据库和安全备份均在项目测试目录临时创建并清理，GitHub 调用全部模拟。测试有意触发一次数据库异常来验证回滚，对应错误日志属于预期测试场景。

尚未重启用户服务，也没有进行新版本的真实浏览器视觉验收或真实 GitHub 联网验证。启用后建议先核对数据库路径和状态，再用手动导出备份检查下载结果，不要用真实数据试验破坏性恢复。
